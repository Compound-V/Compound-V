# CCNA Class 1

Communication - It is the process of sending information from one place to another place using signals via a medium

Information is any type of data we share be it text , voice , image or video

Medium - A link where signals travel from one place to another place it can be wired or wireless

Signal is a way of sending information through a medium, it can be Analog , Digital , Electrical , Optical , Radio&#x20;

Electrical is the branch of engineering where we deal with high power  appliances working on AC  ( AC , TV , etc )

Electronics is the branch of engineering where we deal with low powered devices ( Mobile Phones , Laptop , etc )

Network - is a group of devices connected with each other which share data in form of information signals

Types of Network - depending upon the area, following are some of the main network types ->&#x20;

PAN - Personal Area Network

LAN - Local Area Network

CAN - City Area Network

MAN - Metropolitain Area Network

WAN - Wide Area Network

INTERNET - Interconnected Network



Protocols - set of rules and regulations to do something specific&#x20;

IP - Internet Protocol - gives identification to the device

MAC - Media access card

DNS - Domain Name Server - Converts the name of the website into an IP which the computer can understand

HTTP/HTTPS - Hyper Text Transmission Protocol / Hyper Text Transmission Protocol Secure&#x20;



Cables - Following are some of the important cables used in networks -&#x20;

Co-axial ( the wires we used for dish-antennas , it was used before but rarely used now-a-days cause there is a huge data loss in this cable )

Twisted Pair ( Mostly used in LAN )

Fiber ( Widely used in WAN )
