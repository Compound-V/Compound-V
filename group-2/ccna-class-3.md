# CCNA Class 3

Application Layer -&#x20;

This layer provides an Interface to the user to get on the network or to use the network

eg - Browsers , Whatsapp , Etc

This is the layer which talks to the end hosts/devices.

eg - mail , telnet , ftp , etc&#x20;

* Networking is all about using the applications over the network

Presntation Layer - &#x20;

This layer makes sure that 2 end devices on the network can talk to each other and understand each other regardless of the OS or encryption types they are using.

other functions -&#x20;

encryption , de-cryption , compression , decompression , synchronization&#x20;

Session Layer -&#x20;

It handles the sessions between end hosts and web-servers

means to say it Starts, Maintain and terminates sessions between clients and servers

everything on the web is handled by using sessions.

example - as long as you are using gmail or facebook , you're maintaining the dedicated sessions with their servers. once you logout , you have terminated that session now if you have to login again, you have to create a new session all over&#x20;

NETSTAT command on CMD will help you understand&#x20;
